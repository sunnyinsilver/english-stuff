Nuestra conclusión / Our conclusion

Español: El trabajo se complico bastante al principio por una dificultad de tener todos en nuestras computadoras personales el proyecto actualizado y al mismo tiempo, tuvimos que aprender como utilizar la plataforma GitHub e instalar cada uno el nuevo software de producción de codigo, VS Code.Por el resto del proyecto fuera de eso, el trabajo prosiguio bastante rapido y la unica dificultad se vio a la hora de trabajar con imagenes.


English: There was a complication at he beginning of the project, because we needed to have the website's source code updated and available at the same in each of our own computers; we had to learn how to use Github, and install VS code. After that, it was smooth sailing, and working with images was the only difficult part
